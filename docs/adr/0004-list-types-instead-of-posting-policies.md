# List types instead of posting policies

xListman uses two list types — Discussion and Newsletter — to determine posting behavior, rather than GNU Mailman's four abstract posting policies (open, members-only, moderated, announce-only). Discussion lists are two-way: subscribers can post, with a single "moderation" toggle that holds all posts for approval when enabled. Newsletter lists are one-way: only designated senders (owners or an allowlist) can post; all others are rejected. We chose this approach because it is more opinionated and intuitive than policy selection — list owners think in terms of "is this a discussion or a newsletter," not "which posting policy do I want." The two types cover all real-world use cases. The "Open" policy (anyone can post) is intentionally excluded as a spam risk. "Moderated" maps to a Discussion list with moderation on; "Announce-only" maps to a Newsletter list.
