# CLI-only server administration

Server-level administration (creating domains, creating lists, assigning owners, instance configuration) is done exclusively via CLI commands that talk to the running daemon. There is no web-based server admin interface and no admin accounts. The web UI is reserved for list owners (managing list settings, subscribers, moderation) and subscribers (managing subscriptions, browsing archives), both authenticated via magic links. We chose CLI-only for server admin because instance-level tasks are infrequent, benefit from being scriptable, and would require a separate admin authentication mechanism if exposed via web. Keeping the web UI's auth model purely magic-link-based (no elevated admin role) keeps the authentication system simple and subscriber-focused.
